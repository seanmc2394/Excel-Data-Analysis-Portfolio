# Overview
This project focuses on analysing customer feedback from hotel reviews to identify trends in satisfaction and common themes. Using Excel formulas and functions, text data from Hotel reviews was cleaned, processed, and summarised to uncover insights about guest experiences.
<br>
<br>

## Tools & Techniques Used
- **Excel Text Functions:** LEN, SEARCH, FIND, SUBSTITUTE, IF, COUNTIF, etc.
- **Data Cleaning:** Removing duplicates, handling blanks, trimming and formatting text.
- **Sentiment Grouping:** Categorising reviews by positive/negative tone using keyword logic.
- **Data Visualisation:** Bar charts to highlight review distribution by rating and sentiment.
<br>

## Key Insights
- Majority of reviews were positive, with the average rating around 4–5 stars.
- Frequent positive keywords included “great,” “excellent,” “staff,” and “stay.”
- Negative reviews often focused on “parking,” “price,” and “noise.”
- Quick Excel text-based analysis can surface useful customer insights without the need for advanced software.

# Overview
This project explores the sentiment of 100 hotel reviews. After cleaning the text in Excel, I used PolyAnalyst to run deeper text-mining and sentiment analysis by identifying the tone, common keywords, and parts of speech for each review.
<br>
<br>

## What I Did
- Prepared and structured review data in Excel.
- Imported data into PolyAnalyst for automated sentiment classification.
- Analysed keyword frequency, sentiment polarity, and top recurring themes.
- Created a simple results summary with the key takeaways.
- Included a screenshot of the PolyAnalyst output showing the sentiment distribution and keyword analysis.
<br>

## Key Insights
- Majority of reviews were positive, confirming overall guest satisfaction.
- Most frequent keywords included “great,” “location,” and “clean.”
- PolyAnalyst’s automated sentiment detection aligned closely with manual review results, reinforcing the accuracy of text-mining methods.
<br>

## Tools
**Excel:** Data prep and cleaning.
**PolyAnalyst:** Keyword, part-of-speech, and sentiment analysis.

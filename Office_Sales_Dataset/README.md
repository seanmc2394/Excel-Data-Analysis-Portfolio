# Overview
This project showcases an interactive Excel dashboard built to analyse office sales performance across regions, product categories, and sales channels. It demonstrates advanced Excel functionality, including pivot tables, pivot charts, and custom navigation using buttons and hyperlinks between sheets. The dashboard allows users to quickly visualise sales patterns, explore category performance, and switch seamlessly between analysis views using the built-in menu.
<br>
<br>

## Key Features
- Interactive dashboard with pivot charts and slicers.
- Menu sheet with clickable buttons for easy navigation.
- Clear data visualisation for quick insights.
- Organised pivot tables highlighting regional and category trends.
<br>

## Tools Used
- Microsoft Excel (Pivot Tables, Pivot Charts, Slicers, Sheet Navigation).
- Data visualisation and dashboard design techniques.
<br>

## How to Use
- Start on the Menu sheet to access links to each section.
- Explore pivot table sheets for detailed breakdowns.
- Use slicers to filter and analyse different sales segments.
- Return to the menu using the “Back to Menu” buttons on each sheet.

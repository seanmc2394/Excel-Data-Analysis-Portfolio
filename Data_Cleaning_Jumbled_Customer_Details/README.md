# Overview
This project demonstrates how I transformed a messy, unstructured customer dataset into a clean, structured format using Excel functions. The original dataset contained multiple customer records jumbled into single cells. My goal was to extract individual fields: Name, Address, Age, and Gender-and organise them into a clean table.

The file contains three sheets: 

- Dirty - The original dataset.
- Clean - My cleaned version.
- Work - Showcasing the formulas used to clean the dataset.
<br>

## Tools Used

- Microsoft Excel
- Functions: `TEXTSPLIT`, `MID`, `FIND`, `TRIM`, `SUBSTITUTE`, `PROPER`

## Cleaning Steps

1. Split combined records into individual rows
2. Extract key fields using string functions
3. Standardise formatting (e.g., capitalisation, spacing)
4. Organize into a structured table

## Skills I honed/learned

- Parsing semi-structured text using Excel
- Importance of consistent formatting in data analytics
- Documenting and presenting data cleaning work
